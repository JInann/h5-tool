📺 屏幕镜像
当前设备 —
点击「开始镜像」实时查看手机屏幕。
支持 WebCodecs 的浏览器（Chrome / Edge）走 scrcpy 硬件编码，30–60fps 低延迟；
在画面上点击 = 模拟点击手机，拖动 = 滑动。
画面点击映射为设备真实坐标；按住拖动可滑动/滚动页面。
屏幕流需 iPhone 系统 iOS 27+（iOS 26 及更早不开放 displayservice，换机无用）；首次连接需 10~40 秒（起隧道 + 设备开媒体流）。Windows 浏览器需支持 HEVC 解码（Chrome/Edge 需系统「HEVC 视频扩展」，Safari 无需）。点画面=点击，按住拖动=滑动。

⚙ 控制面板
与运行在你自己电脑上的 h5-tool 后端通信，默认 127.0.0.1:12787；改了端口或部署到服务器后在这里调整，保存立即重连。
DevTools 面板资源（inspector.html 等）按需从下方地址拉取，缓存到本地 devtools-local/.remote-cache/；支持 http(s) URL 或本地 front_end 目录路径。保存后立即生效，源变更会自动清空旧缓存。
